## Selected work

### ArguLab — AI communication practice & personalized training

**My flagship project, built collaboratively and deployed across Netlify, Render and Supabase.**

Nine practice modes span debate, group discussion, interviews, public speaking, extempore, negotiation, cases, real-world simulation and observer analysis. Structured reviews cover claims, evidence, fallacies, strengths, weaknesses and next steps.

**The engineering idea:** a personalization loop connects session summaries, strengths/weaknesses and persistent user context to future AI training. The richer context workflow is rolling into ArguLab; its implementation and release status are documented below. Around that loop: streamed responses, authenticated APIs, resumable history, progress tracking, reports, JSON export and optional speech tools, with responsive mobile web support.

**React 19 · TypeScript · Fastify · Better Auth · AI SDK / Groq · PostgreSQL · Docker**

Recorded v3.0.2 verification: **58 backend/integration + 21 browser tests**, with four additional release-tool tests. Application source is private; the public repository documents the product, architecture and release evidence.

**[Open ArguLab →](https://argulab.netlify.app/dashboard)** · [Public repository](https://github.com/Laabh-Gupta/argu-lab) · [Engineering & personalization](https://github.com/Laabh-Gupta/argu-lab/blob/main/docs/ENGINEERING.md) · [Release evidence](https://github.com/Laabh-Gupta/argu-lab/blob/main/docs/releases/3.0.2.md)

### Voice Anti-Spoofing — deep learning through to model serving

Mel spectrograms, CNNs, Vision Transformers and augmentation for human-versus-generated speech classification, connected to a React interface and FastAPI inference service.

**PyTorch · Torchaudio · FastAPI · React · Hugging Face Hub**<br>
Original-project result: **99.75% ViT test accuracy**. The deployed demo uses the baseline CNN; the research README explains the evaluation provenance and limits.

[Live demo](https://voiceantispoofing.netlify.app/) · [Application source](https://github.com/Laabh-Gupta/Voice-Anti-Spoofing-Web-App) · [Training & evaluation](https://github.com/Laabh-Gupta/Voice_Anti_Spoofing_System)

**Python · LangChain · ChromaDB · Ollama · Streamlit · RAGAS**<br>
